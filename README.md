Egoist

Egoist — лёгкий инструмент для управления блокировщиками на чистом WinAPI. Один .exe без зависимостей, без ImGui, без Qt.

Возможности
Гибкое управление блокировщиками через удобный интерфейс
Чекбоксы для каждого блокировщика — добавляются автоматически
Поддержка русского и английского языков
Встроенная поддержка PNG/JPG изображений
Никаких внешних зависимостей — один исполняемый файл
Установка

Актуальные сборки доступны на странице релизов

Скачайте .exe файл последней версии.
Запустите — программа попросит права администратора (необходимы для записи политик браузеров).
Сборка вручную

Visual Studio 2022 (проще всего)

Откройте Egoist.sln, выберите конфигурацию Release / x64, затем Ctrl+Shift+B.
Готовый exe: bin\x64\Release\Egoist.exe.

CMake + MSVC

cmake -S . -B build
cmake --build build --config Release

MinGW (g++)

cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build

Также можно открыть папку проекта в Visual Studio (File > Open > Folder) или в VS Code с расширением CMake Tools.

Структура проекта
Файл	Описание
src/main.cpp	Главное окно
src/about.cpp	Окно «О программе»
src/settings_window.cpp	Окно «Настройки»
src/Blockers.cpp	Список блокировщиков (сюда добавлять новые)
src/Lang.cpp	Все тексты RU/EN
src/Ui.cpp	Шрифты, DPI, тема
src/Image.cpp	Загрузка PNG/JPG
resources/ + src/egoist.rc	Картинки, встраиваемые в exe
Как добавить
Картинку: положите файл в resources/, добавьте строку в egoist.rc и #define в resource.h, затем используйте Img::FromResource(IDR_X) и Img::Draw(dc, bmp, x, y, w, h) — размер любой.
Блокировщик: реализуйте функции isActive и apply, добавьте строку в Blockers() — чекбокс в окне появится автоматически.
Текст: добавьте пункт в enum Str и по одной строке в обе таблицы в Lang.cpp.
