# Egoist

**Egoist** — лёгкая программа для отключения Push-уведомлений и другого. Написана на чистом WinAPI: один `.exe`, без ImGui, без Qt, без зависимостей.

</div>

## Возможности

- Гибкое управление блокировщиками через удобный интерфейс
- Чекбоксы для каждого блокировщика, добавляются автоматически
- Поддержка русского и английского языков
- Встроенная поддержка PNG/JPG изображений
- Никаких внешних зависимостей, один исполняемый файл

## Установка

> Актуальные сборки доступны на странице [релизов](https://github.com/LinkSyne/Egoist/releases)

- Скачайте `.exe` файл последней версии.
- Запустите его. Программа попросит права администратора, они нужны для записи политик браузеров.

## Сборка вручную

**Visual Studio 2022** (проще всего)

- Откройте `Egoist.sln`.
- Выберите конфигурацию `Release / x64`.
- Нажмите `Ctrl+Shift+B`.
- Готовый файл: `bin\x64\Release\Egoist.exe`.

**CMake + MSVC**

```bash
cmake -S . -B build
cmake --build build --config Release
```

**MinGW (g++)**

```bash
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Также можно открыть папку проекта в Visual Studio (`File > Open > Folder`) или в VS Code с расширением CMake Tools.

## Структура проекта

| Файл | Описание |
|---|---|
| `src/main.cpp` | Главное окно |
| `src/about.cpp` | Окно «О программе» |
| `src/settings_window.cpp` | Окно «Настройки» |
| `src/Blockers.cpp` | **Список блокировщиков** (сюда добавлять новые) |
| `src/Lang.cpp` | Все тексты RU/EN |
| `src/Ui.cpp` | Шрифты, DPI, тема |
| `src/Image.cpp` | Загрузка PNG/JPG |
| `resources/` + `src/egoist.rc` | Картинки, встраиваемые в exe |

## Как добавить

**Картинку**

- Положите файл в `resources/`.
- Добавьте строку в `egoist.rc` и `#define` в `resource.h`.
- Используйте в коде, размер любой:

```cpp
Img::FromResource(IDR_X);
Img::Draw(dc, bmp, x, y, w, h);
```

**Блокировщик**

- Реализуйте функции `isActive` и `apply`.
- Добавьте строку в `Blockers()`. Чекбокс в окне появится автоматически.

**Текст**

- Добавьте пункт в `enum Str`.
- Добавьте по одной строке в обе таблицы в `Lang.cpp`.
